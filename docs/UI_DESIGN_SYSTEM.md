# UI Design System
Aim for a clear, trustworthy, modern, mobile-first interface. Prioritise useful product information over decoration.

Listing cards should show the primary image, brand/model, condition, NGN price, location, availability, and seller context. Never imply verification without evidence.

Data-backed screens should consider loading, empty, success, validation error, server/network error, and permission-denied states. Use semantic HTML, associated labels, keyboard-operable controls, visible focus, meaningful alt text, readable contrast, and cues beyond colour alone. Respect reduced motion.

Inspect existing components/tokens before adding duplicates. Shared UI changes require coordination and responsive regression checks. Clearly label promoted listings if implemented.
