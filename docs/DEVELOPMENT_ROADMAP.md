# Development Roadmap
Provisional; a phase is not complete until verified and approved.

0. Foundation: confirm frameworks, package manager, database, auth, image storage, scripts, deployment, ownership, and baseline checks.
1. Browse marketplace: responsive listing discovery/details, search/filter/sort/pagination, loading/empty/error states.
2. Accounts and sellers: auth/profile, create/edit/archive own listings, ownership checks, safe image storage, dealer storefront if approved.
3. Buyer interaction: favourites, enquiries/messages or offers if approved, reports/moderation, spam/rate-limit controls.
4. Launch readiness: critical-flow and permission tests, accessibility/mobile checks, security review, environment docs, monitoring, backups/rollback, owner acceptance.

Deferred until separately approved: payments/escrow, physical inspection, AI recognition/fraud scoring, push notifications, advanced analytics. Release requires acceptance criteria, recorded checks, security/privacy review, updated docs, and owner approval.
