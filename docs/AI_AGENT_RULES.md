# AI Agent Rules
Applies to all AI assistants and coding agents.

- Read `AGENTS.md`, relevant specs, task queue, and latest logs before work.
- Inspect branch, git status, files, and manifests before editing.
- Work only on an assigned, unblocked task and approved branch.
- Read files before editing; preserve uncommitted changes.
- Make the smallest complete change; avoid speculative refactors and unnecessary dependencies.
- Never push to main, force-push, or conceal failed operations.
- Do not invent routes, schema, env variables, scripts, credentials, or test results.
- Validate untrusted input server-side; enforce ownership/roles; use parameterised DB operations; safely render user content; protect uploads; return safe errors.
- Pause for destructive changes, production access, payment/escrow, identity verification, or unclear security impact.
- Review diff; run only existing commands; record exact results and unrun checks.
- Update task queue, work log, handoff log, board, and changelog as appropriate.
