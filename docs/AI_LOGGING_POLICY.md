# AI Logging Policy
Log meaningful work with timestamp/timezone, tool/agent, role ID, task ID, branch, goal, files, summary, exact commands/outcomes, checks not run and reasons, risks, blockers, next step, and reviewer.

Never log passwords, API keys, tokens, private keys, full environment files, unnecessary personal information, private messages, payment data, or production records. Separate attempts from successful actions. Record errors honestly; append corrections rather than silently rewriting history. Human owner reviews high-risk changes.
