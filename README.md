# Phone Village
A Nigerian marketplace for discovering and listing phones.

## Status
Early-stage project. Planning documentation is not proof that a feature is implemented.

- `docs/AI_WORK_LOG.md`, `docs/AI_HANDOFF_LOG.md`, `docs/AI_LOGGING_POLICY.md`: audit trail
